mavr | componentes visuales

Ejercicios · UD3

Ejercicios de la UD3 · Creación de componentes visuales. No forman parte de la aplicación de gestión: en ellos se construye paso a paso una librería propia de componentes (mavr-texto, mavr-ui.js y mavr-componentes.js). Mantienen el código del material de referencia con el estilo de mavr.

Los formularios envían a procesa.php: arranca el servidor con php -S localhost:8000 desde esta carpeta y entra en http://localhost:8000/. Para ver los componentes sin enviar el formulario basta con python -m http.server 8000.
