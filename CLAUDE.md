# DAM26-27 · Desarrollo de Interfaces (2º DAM)

## Contexto
- Proyectos que uso como material de clase en Desarrollo de Interfaces (2º DAM). El alumnado los seguirá paso a paso.
- Se construyen por iteraciones que avanzan al ritmo del temario (UD1, UD2…).

## Al ser material docente
- Tengo que entender cada línea y poder explicarla en clase: explica el porqué de cada decisión.
- Comentarios en el código pensados para que los entienda el alumnado de 2º DAM.
- Avanza en pasos pequeños, para que cada paso se pueda enseñar por separado.

## Estructura de cada iteración
Cada iteración es una carpeta numerada `00X-nombre/` con:
```
index.html
css/estilo.css
js/componentes.js
data/*.json
img/
templates/
README.md
```
- El README de cada iteración explica qué se ha añadido, qué contenidos de la UD cubre y cómo probarlo.

## Reglas de este proyecto
- No copiar código de los proyectos de mi antiguo tutor. Se pueden usar como referencia de qué funcionalidades hay, pero el código se escribe desde cero.
